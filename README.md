# HR-Assistant

A simple HR assistant built using LangChain, OpenAI, and Streamlit.
It provides HR-related responses by using mock tools to retrieve employee details, check leave balances, and generate interview questions.

🚀 Features

Retrieve employee information by ID

Check leave balance

Generate interview questions based on job roles

Easy-to-use Streamlit interface

Uses LangChain functional agents

Mocked tools (no real database needed)

🛠️ Tech Stack

Python

Streamlit

LangChain

OpenAI API

python-dotenv

🔑 Create an .env File

You need to create a .env file in the project folder and add your API keys before running the app:

OPENAI_API_KEY=your_openai_key_here
LANGCHAIN_API_KEY=your_langchain_key_here
